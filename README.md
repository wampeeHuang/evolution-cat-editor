# 进化猫图文编辑器 · v1.2.0

工具架“进化猫图文编辑器”按需启动/停止；入口http://127.0.0.1:8797/。首页自动列出config.json内容根直接子目录中的兼容稿件，点击后每篇独立地址，可多标签页编辑。原/index.html现在也进入目录。

内容不迁入工具：各篇index.html的document-state是权威内容，spec.json为派生；通用web/和server.py/render.cjs在本工具。在线统一服务组件，本期assets/editor仅为离线阅读快照。兼容格式evolution-cat-photo-v2，支持1～50张；其他旧格式不会自动转换或改写。

保存检查HTML SHA256；其他标签或Agent修改后409提示，当前编辑与浏览器草稿保留，可下载冲突副本后人工合并。不同篇可独立保存；内容根变化/期次改名会改变地址。

导出提交不可变快照，单worker排队，实时显示前方任务数。默认输出当前期次目录；禁止写入另一篇。导出期间原稿更新时不覆盖本篇发布图，任务快照保留。任务记录在_runtime/jobs，服务重启将未完成任务标为失败，不自动恢复执行。已完成任务可继续查看。请勿在有未保存编辑或导出任务时停止服务。

字体提供方字荐8770为可选；使用自选字体须运行它。渲染依赖已安装Node、Playwright与Edge，路径见render.cjs，跨机需适配。只本机监听，无上传发布或账号操作。

版本日志VERSION/CHANGELOG.md由页面直接读取。交接HANDOFF.md，验收_runtime/验收.md；verify.py核对隔离测试证据，测试素材只在_runtime/不进源码。停止脚本核对命令归属。工具位于既有D:/tools Git仓，窄范围提交；不另建仓库。
